# Microsoft Store listing assets

The MSI/EXE Store pipeline publishes the metadata in `metadata.json` and the
English listing assets under `en-us`.

- Put one square Store logo in `en-us/logos`.
- Put one to ten application screenshots in `en-us/screenshots`.
- Images are uploaded in alphabetical order.
- Updating these files replaces the corresponding English Store assets on the
  next submission.

Screenshots must accurately represent the released application and must not
contain private task or transcript content.
