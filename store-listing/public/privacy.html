TaskLens Privacy Policy

TaskLens stores tasks and work areas locally on the user's Windows device. The app does not require an account and does not include advertising or analytics.

Pasted text is processed on the device using the Windows system language model when available. On unsupported systems, it is processed by TaskLens's local rules-based extractor. This release does not send pasted text to a cloud AI service.

TaskLens does not access email, Teams, files, contacts, or calendars in this release.
