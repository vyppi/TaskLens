# Privacy policy for TaskLens

TaskLens stores tasks and work areas locally on the user's Windows device. The
app does not require an account and does not include advertising or analytics.

When no cloud AI provider is configured, pasted text is processed on the device.
If the user configures a cloud AI endpoint through environment variables, text
submitted for extraction is sent to that provider at the user's request and is
subject to that provider's terms and privacy policy. TaskLens does not store the
configured API key.

TaskLens does not access email, Teams, files, contacts, or calendars in this
release.
